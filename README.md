# Netflix Content Analysis

## Project Overview
This project analyzes Netflix content using Python, Pandas, and Matplotlib.

## Objective
To explore Netflix dataset trends such as:
- Movies vs TV Shows
- Top countries producing content
- Top directors
- Content growth over the years

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Insights
- Netflix has more Movies than TV Shows
- The United States produces the most Netflix content
- Netflix content has grown significantly over the years

## Files Included
- Netflix_Analysis.ipynb
- netflix_dataset.csv
